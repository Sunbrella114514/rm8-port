# 《大富翁8》AI脚本逆向分析报告

> **主代理核实（以本表为准）**：用脚本把 16 个 AI 中 `randint(1, 100) <= N` 的三处概率替换掉后比较，除 AI_05/AI_14 外其余 14 个 AI 的代码**完全相同**。AI_05 与 AI_14 只是把 `SBuy` 改成直接 `return -1`（不买股票）。也就是说，各角色 AI 的差异只有下面 3 个数：
>
> | AI | 角色 | Count 概率 | SBuy 买股概率 | Borrow 借款概率 |
> |---|---|---|---|---|
> | AI_01 | 大老千 | 90 | 50 | 60 |
> | AI_02 | 萊娜 | 70 | 20 | 60 |
> | AI_03 | 錢夫人 | 90 | 50 | 100 |
> | AI_04 | 忍太郎 | 50 | 30 | 20 |
> | AI_05 | 阿土仔 | 30 | 禁用 | 50 |
> | AI_06 | 孫小美 | 50 | 10 | 50 |
> | AI_07 | 舞美拉 | 50 | 20 | 70 |
> | AI_08 | 金貝貝 | 80 | 10 | 30 |
> | AI_09 | 沙隆巴斯 | 90 | 40 | 100 |
> | AI_10 | 烏咪 | 40 | 30 | 20 |
> | AI_11 | 金泡菜 | 60 | 20 | 40 |
> | AI_12 | 酷娃 | 70 | 30 | 100 |
> | AI_13 | 伊格魯 | 60 | 40 | 10 |
> | AI_14 | 星期三 | 30 | 禁用 | 50 |
> | AI_15 | 詹姆斯 | 60 | 50 | 90 |
> | AI_16 | 莎拉公主 | 70 | 20 | 30 |
>
> 说明：Count 概率 = 在法院**提出控告**的概率（返回 0~2），其余情况返回 3 表示不控告；SBuy = 资产 > 60000×物价指数时尝试买股票的概率；Borrow = 资产在 5 万~30 万×物价指数之间时借款的概率（低于 5 万×物价指数时必定借款）。下文分组描述如与本表冲突，以本表为准。“文件大小”一节中的字节数与实际 .pyc 大小（6169/6174 与 5435 字节）不符，可忽略。
>
> 另外：AI 难度主要由卡片脚本中的 `Role.GameDffty() >= 3` 分支决定（乌龟卡、路障卡、停留卡会针对对手），对应 init.txt 中的 `difficuty`。

> **回调语义（已由 exe 反编译验证，详见 exe_internals.md §3）**：
> - `Access`：停在**银行**时调用。返回负数 = 把 |n| 元现金**存入**银行，正数 = 取出 n 元，0 = 不操作。所以持有均富卡（Id 21）时 `return -a` 表示把现金全部存起来，躲开均富。
> - `Borrow`：同样在银行调用，而且只在**当前没有贷款**时才询问；返回值即贷款金额。
> - `Count`：停在**法院**时调用（并不是“操作频率”）。返回 0 = 以「藐視電腦」控告随机对手（成功率 60%，对方入狱 5 天）；1 =「亂用卡片」（成功率 70%，入狱 3 天）；2 =「強收地租」（成功率 60%，罚款 5000×物价指数）；3 = 不控告。因此表中的“Count 概率”实际上是**AI 去打官司的概率**。
> - `DiceNum`：返回本回合要掷的骰子数，必须在 1 ~ 交通工具数之间才生效。
> - `Answer`：问答点调用，返回 0/1 决定走哪条答题分支（推测 1 = 答对，因此 AI 的答对率约为 50%）。
> - 股市阶段的调用顺序：`SSellAll`（非 0 = 清仓）→ 循环 `SSell`（返回要卖的股票，-1 结束）→ `SBuy`（选股）→ `SBuySum(股票)`（买入股数）。
> - `GameDffty()` 读取的是 init.txt 中的 `difficuty`。

## 3. 决策函数详细说明

### 3.1 Access(param) - 银行存取款决策

**调用时机：** 推测为玩家访问银行/money box时（按回合）

**返回值含义：**
- 正数：存入金额
- 负数：取出金额
- 0：不进行存取操作

**代码逻辑分析：**

```python
def Access(param):
    cur = Role.CurRole()
    a = Role.Cash(cur)           # 当前现金
    b = Role.Fund(cur)           # 基金/存款
    if Role.HasCard(cur, 21):    # 卡牌21？
        return -a                # 取出全部现金
    m = a + b                    # 总资产
    p = Role.PriceIndex()        # 价格指数
    r = randint(0, 20)           # 随机基数[0-20]
    
    # 情况1：现金少于5000*价格指数
    if a < 5000 * p:
        if b < 5000 * p:
            return b             # 取出全部基金
        else:
            r = r + 50           # 基数→[50-70]
            n = b * r / 100      # 取出部分基金(50-70%)
            s = n - 30000 * p    # 超额部分
            if s > 0:
                n = n - randint(s - 5000, s + 5000)  # 随机浮动
            return n
    
    # 情况2：现金充足，根据游戏日期调整
    d = Role.GameDay()
    if d <= 7:      r = r + 60   # 早期：60-80
    elif d >= 26:   r = r + 20   # 晚期：20-40
    else:           r = r + 40   # 中期：40-60
    
    n = m * r / 100 - a          # 计算存入金额
    if n > 5000 * p or n < -5000 * p:
        if randint(0, 1) == 1:
            return n
    return 0
```

**关键阈值分析：**
- `5000 * PriceIndex`：触发基金取出的现金不足线
- `30000 * PriceIndex`：基金部分取出的参考额度
- `randint(0, 20)` → 根据日期→ `r / 100` ：50%-80%的资产调整比例
- **推测原理：** 前期手紧时取钱，后期资产充足时存钱，用于平衡现金流

### 3.6 SBuy(param) - 股票购买决策

**调用时机：** 推测为每回合或定期尝试购买股票

**返回值含义：**
- -1：不购买股票
- >=0：股票代码（购买该股票）

**代码逻辑（标准版本，AI_01为例）：**
```python
def SBuy(param):
    cur = Role.CurRole()
    a = Role.Cash(cur)
    b = Role.Fund(cur)
    m = a + b
    p = Role.PriceIndex()
    
    # 条件1：资产足够（60000*PriceIndex以上）
    # 条件2：随机概率通过（各AI不同）
    if m > 60000 * p and randint(1, 100) <= THRESHOLD:
        n = b * 60 / 100         # 用基金的60%额度
        if n > 20000:            # 额度需>20000
            sum = Stock.Sum()
            for i in range(sum):
                ap = Stock.AvrPrice(i)      # 股票平均价格
                cp = Stock.CurPrice(i)      # 〔string.bin#6101〕
                f = Stock.FlowSum(i)        # 流动量
                if Stock.TradeEnable(i) and f > 100:
                    r = cp / ap             # 价格比
                    if r < 0.6:             # 价格<60%
                        if randint(1, 10) < 6:  # 60%几率
                            return i
                    elif r < 0.75:          # 价格60-75%
                        if randint(1, 10) < 4:  # 40%几率
                            return i
                    elif r < 0.9:           # 价格75-90%
                        if randint(1, 10) < 2:  # 20%几率
                            return i
    return -1
```

**关键参数对比：**

| AI | THRESHOLD | 特征 |
|----|-----------|------|
| AI_05, AI_14 | ∞ (无) | **完全禁用**，直接返回-1 |
| AI_06, AI_08 | 10% | 很少考虑 |
| AI_02, AI_07, AI_11, AI_16 | 20% | 较少考虑 |
| AI_04, AI_10, AI_12 | 30% | 中等 |
| AI_09, AI_13 | 40% | 较多 |
| AI_01, AI_03, AI_15 | 50% | 积极 |

**选股逻辑分析：**
- 只选流动量>100的股票
- 优先选便宜股（价格越低触发概率越高）：
  - r<0.6：60%机会买
  - r<0.75：40%机会买
  - r<0.9：20%机会买

**推测原理：** 
- AI寻找"低价股"反弹机会
- 资产要求60000*PriceIndex保证不会破产
- AI_05/14是为了测试纯陆地投资策略（无股票干扰）

### 3.7 SSell(param) - 单股卖出决策

**调用时机：** 推测为每回合尝试卖出持有的股票之一

**返回值含义：**
- -1：不卖出任何股票
- >=0：股票代码（卖出该股票）

**代码逻辑（所有16个AI相同）：**
```python
def SSell(param):
    cur = Role.CurRole()
    sum = Role.StockSum(cur)    # 持有股票数
    if sum > 0:
        for i in range(sum):
            s = Role.Stock(cur, i)          # 第i支股票代码
            if s >= 0:
                if Stock.TradeEnable(s):
                    pa = Role.StockPrice(cur, i)    # 买入价
                    pb = Stock.CurPrice(s)          # 当前价
                    r = pa / pb                     # 价格比（买入价/当前价）
                    
                    if r > 1.8:                 # 翻倍以上（赚80%+）
                        if randint(1, 10) < 6:  # 60%机会
                            return s
                    elif r > 1.5:               # 赚50%以上
                        if randint(1, 10) < 4:  # 40%机会
                            return s
                    elif r > 1.2:               # 赚20%以上
                        if randint(1, 10) < 2:  # 20%机会
                            return s
    
    return -1
```

**关键参数分析：**
- 利润率越高，卖出意愿越强
- r > 1.8（收益>80%）：优先卖出
- r < 1.2（收益<20%）：不卖（持有等待）
- **推测原理：** 贪心策略，见好就收，等待高利润时机

### 3.8 SSellAll(param) - 全部卖出股票决策

**调用时机：** 推测为面临破产威胁时的紧急卖出

**返回值含义：**
- 0：不卖出
- 1：全部卖出所有股票

**代码逻辑（所有16个AI相同）：**
```python
def SSellAll(param):
    cur = Role.CurRole()
    cash = Role.Cash(cur)
    fund = Role.Fund(cur)
    m = cash + fund             # 总资产
    p = Role.PriceIndex()
    
    # 条件1：资产严重不足
    if m < 10000 * p:
        return 1
    
    # 条件2：借钱快到期且资不抵债
    b = Role.Borrow(cur)        # 欠债
    d = Role.PaybackDay(cur)    # 还款日（剩余天数）
    if b > 0 and d <= 5:
        b = b + 10000 * p       # 预留10000*p
        if m < b:
            return 1
    
    # 条件3：即将踩到高租金地产
    if Role.HasCard(cur, 11) == 0:  # 无保护卡牌
        dn = Role.TrfTool(cur)      # 转移工具（骰子数）
        range = dn * 6              # 展望距离
        ss = Role.StPoints(cur, range, 1)  # 前方地点
        for s in ss:
            t = StPoint.Terra(s)
            owner = Terra.Owner(t)
            if owner >= 0 and owner != cur:
                rent = Terra.Rent(t, 1)
                if rent >= m and randint(3, 16) >= range:
                    return 1
    
    return 0
```

**关键阈值：**
- `10000 * PriceIndex`：最低生存线
- `d <= 5`：借钱还款期限窗口
- `rent >= m`：即将无力支付的地产判定

**推测原理：** 三层防守：
1. 资产太少→全卖
2. 债务危机→全卖
3. 高租金威胁→全卖

### 3.9 SBuySum(param) - 股票购买数量

**调用时机：** SBuy() 选中股票后，决定购买数量

**返回值含义：**
- 正整数：购买该数量的股票
- 0：不购买

**代码逻辑（所有16个AI相同）：**
```python
def SBuySum(param):  # param为股票代码
    if Stock.TradeEnable(param):
        cur = Role.CurRole()
        a = Role.Fund(cur)
        m = a * 60 / 100        # 用基金的60%
        n = 0
        ap = Stock.AvrPrice(param)
        cp = Stock.CurPrice(param)
        sum = Stock.FlowSum(param)  # 股票流动量上限
        r = cp / ap
        
        per = randint(1, 20)    # 随机调整[1-20]%
        if r < 0.6:             # 价格<平均价的60%
            n = m * (per + 80) / (cp * 100)     # 按80-100%额度买
        elif r < 0.75:          # 价格60-75%
            n = m * (60 + per) / (cp * 100)     # 按60-80%额度买
        elif r < 0.9:           # 价格75-90%
            n = m * (40 + per) / (cp * 100)     # 按40-60%额度买
        
        if n > sum:             # 流动量限制
            n = sum
        return n
    return 0
```

**关键参数分析：**
- 用基金的60%购买预算
- 价格越便宜，购买量越多（80-100%）→ 摊低成本
- 价格越接近平均价，购买量越少（40-60%）
- **推测原理：** 低价时重仓，高价时轻仓，动态〔string.bin#6304〕

### 3.10 DiceNum(param) - 骰子数量决策

**调用时机：** 推测为行动回合，玩家可选择使用几颗骰子

**返回值含义：**
- 1: 使用1颗骰子（最保险）
- 2-n: 使用多颗骰子（n由TrfTool决定）

**代码逻辑（所有16个AI相同）：**
```python
def DiceNum(param):
    cur = Role.CurRole()
    a = 1
    n = Role.TrfTool(cur) + 1   # 最多可用的骰子数
    if n > 1:
        ss = Role.StPoints(cur, 5, 1)  # 检查前5格内的地点
        g = 0   # 好地点计数
        b = 0   # 坏地点计数
        ta = 0  # 我的地产计数
        tb = 0  # 别人的地产计数
        
        for s in ss:
            npc = StPoint.Npc(s)        # 检查NPC
            if npc >= 0:
                if Npc.Goodness(npc):   # 好心人
                    g = g + 1
                else:                   # 坏人
                    b = b + 1
            
            t = StPoint.Terra(s)        # 检查地产
            if t != 0:
                owner = Terra.Owner(t)
                if owner < 0 or owner == cur:
                    ta = ta + 1         # 空地或我的
                else:
                    tb = tb + 1         # 别人的
        
        # 决策逻辑
        if g > b:                       # 好人多
            return 1                    # 用1颗，走远距离
        elif b > g:                     # 坏人多
            a = randint(2, n)
            return a                    # 用多颗，快速经过
        
        tm = ta - tb
        if tm > 2:                      # 我的地多
            return 1                    # 用1颗，走远
        elif tm < -2:                   # 别人的地多
            a = randint(2, n)
            return a                    # 用多颗，快速走
        
        a = randint(1, n)               # 其他：随机
    return a
```

**关键决策树：**
```
前5格判定：
  ├─ 好人>坏人 → 用1颗（保险）
  ├─ 坏人>好人 → 用2-n颗（快速通过）
  ├─ 我的地≥3个 → 用1颗（走长距离）
  ├─ 别人的地≥3个 → 用2-n颗（快速脱险）
  └─ 其他情况 → 1-n颗随机
```

**推测原理：** 
- 避免踩到坏人和别人的地
- 靠近好人时保险（多回合互动）

### 3.11 Borrow(param) - 借钱决策

**调用时机：** 推测为每回合或资金不足时自动判定是否借钱

**返回值含义：**
- 0：不借钱
- 正数：借钱金额（100000, 200000, 300000）

**代码逻辑（各AI THRESHOLD不同）：**
```python
def Borrow(param):
    cur = Role.CurRole()
    a = Role.Cash(cur)
    b = Role.Fund(cur)
    m = a + b
    p = Role.PriceIndex()
    
    if m < 300000 * p:
        if m < 50000 * p or randint(1, 100) <= THRESHOLD:
            r = randint(1, 10)
            if r < 4:           # 30%
                return 100000
            elif r < 8:         # 40%
                return 200000
            else:               # 30%
                return 300000
    return 0
```

**关键参数：**

| AI | THRESHOLD | 倾向 |
|----|-----------|------|
| AI_13 | 10% | 极不爱借 |
| AI_04, AI_10, AI_16 | 20% | 很少借 |
| AI_05, AI_14 | 50% | 适度 |
| AI_08 | 30% | 较少 |
| AI_11 | 40% | 中等 |
| AI_02, AI_01 | 60% | 积极借 |
| AI_07 | 70% | 更积极 |
| AI_03, AI_09, AI_12 | 100% | **总是尝试** |
| AI_15 | 90% | 几乎总是 |

**借钱额度分布：**
- 30%：借100000
- 40%：借200000
- 30%：借300000

**触发条件：**
- 资产 < 300000*PriceIndex（总资产低于此线）
- 且：资产 < 50000*PriceIndex（极度缺钱） 或 随机通过
  
**推测原理：**
- 当总资产低于300000*PriceIndex时考虑借钱
- 极度缺钱（<50000*PriceIndex）时无条件借钱
- THRESHOLD越高=AI越积极借钱=风险偏好高

## 5. 关键发现总结

### 发现1：AI_05/AI_14完全相同且禁用股票
- 两个文件哈希值不同（因编译时间戳差异），但代码完全相同
- 唯一显著差异：SBuy()直接返回-1，禁用所有股票交易
- 推测：这是"纯陆地投资型"AI的测试版本

### 发现2：核心变量只有3个
- **Count 控告概率**（30%-90%）：在法院时控告对手的概率
- **SBuy概率**（10%-50%或无）：决定股票投资水平
- **Borrow阈值**（10%-100%）：决定风险偏好
- 其他11个函数在所有AI间几乎完全相同

### 发现3：SBuy定价逻辑为典型"低价摊平"策略
- 价格越低购买量越多（r<0.6时用基金的80-100%）
- 价格接近均价时谨慎（r<0.9时用基金的40-60%）
- 选股偏向流动量>100的"活跃股"
