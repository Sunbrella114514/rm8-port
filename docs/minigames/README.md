## 共同接口（与主程序）
- DLL 导出 `LG_create_game` / `LG_delete_game`。游戏对象虚表前 8 项依次为 Init、GetResult、Update、Draw、KeyDown、KeyUp、MouseButton、MouseMove（已在 18/23 中核对）。
- 主程序一侧由 `CMiniGameHost`（vtable 0x5E88E0 / 0x5E8928）加载 DLL、转发输入、取回结果，并据结果发点券、卡片或施加住院等效果。
- 电脑玩家不运行 DLL，由主程序 `FUN_004fcb10` 按 init.txt 的 `difficuty` 随机生成结果。
- 6 个 DLL 共用一套框架（UI 控件、精灵、INI 解析，约 360 个函数）；该框架只按发布版分析一次，名称按函数体哈希同步到各 DLL。18 和 23 是调试版编译。
- 两个 DLL 请求的 `L001.mp3` 实际不会播放（主程序该接口恒返回 −1），背景音乐由主程序按轨道号播放。

## 修改提示
- 奖励阈值、得分数值都写死在各 DLL 代码里，要改需要二进制补丁（各文档已给出函数地址）。
- 电脑玩家的“小游戏成绩”在主程序 0x4FCB10，改这里不影响玩家。
