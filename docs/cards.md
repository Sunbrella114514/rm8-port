## 2. condition 位域（**已由 exe 代码验证**：FUN_004ad440 卡片可用性检查）

card.bin 由 FUN_004adec0 读入，每张卡对应一个结构体：+0x204 Id、+0x208 type、+0x20C condition、+0x210 level、+0x214 ticket、+0x218 speakNo[3]。使用卡片时，FUN_004ad440 按下面的规则检查 condition：

| 位 | 含义 | exe 中的判断 |
|---|---|---|
| `0xFF000000` 使用前提（脚下格子） | 0x01 无要求；0x02 脚下必须是住宅地（地块 type==1）；0x04 脚下必须是**自己的**地；0x08 脚下必须是**非自己的**地；0x10 脚下必须是无主地（没有卡使用） | 不满足时直接返回“不可使用” |
| `0x000000FF` 目标类型 | 0x01 角色、0x02 道路点、0x04 街道、0x08 土地、0x10 无需目标、0x20 NPC | 决定弹出哪种选择界面 |
| `0x0000F000` 选择范围 | 0x8 自身位置（土地类：不弹选择，直接作用于脚下）；0x4 所在街道（街道类：不弹选择）；0x2 附近；0x1 全图 | `&0xF000 == 0x8000/0x4000` 时跳过选择 |
| `0x00000F00` 角色归属 | 0x1 不限、0x2 仅自己（角色类：`&0xF00 == 0x200` 时不弹选择，直接对自己）、0x4 仅他人 | 同上 |
| `0x00FF0000` 土地过滤 | 购地 0x01、建屋 0x04、拆屋 0x02、交换 0x01、怪兽 0x02 | 连同低 24 位一起传给选择界面 FUN_00484890，具体含义待验证（推测：可交易/有建筑/可加盖） |

其他已验证规则：`type==2`（嫁祸卡）不能主动使用；`type==4`（神明卡）的角色选择会额外带上 0x2000 标志；`type!=1` 的道路点卡会额外带上 0x100 标志。

**改卡示例**：想让购地卡可以在空地上用，把最高字节从 0x08 改成 0x01（`0x08018408` → `0x01018408`）；想让建屋卡在任意位置对自己的地使用，保持 `0x01042108` 即可。

## 5. 修改指南

1. **改价格/等级/条件**：编辑 `out/config_utf8/card.bin.txt`（UTF-8）→ `python scripts/rm8crypt.py encutf8 auto out/config_utf8/card.bin.txt card.bin`（自动转 Big5 并用密钥 `tiep8jdg` 加密）→ 覆盖 `Config/card.bin`（先备份）。注意繁体字须是 Big5 内有的字。
2. **改效果/AI**：编辑 `out/pysrc_clean/CardPy_xx.py`（必须是 Python 2.4 语法）→ `py32 -I scripts/py24c.py CardPy_xx.py` 生成 `.pyc` → 覆盖 `Pysrc/CardPy_xx.pyc`。编译器就是游戏自带的 `Python24.dll`，100/105 个脚本可做到字节码完全一致。
3. 每张卡至少要有 `Execute` 和 `Competence` 两个函数；Execute 返回 1 表示成功使用（扣卡），0 表示失败。
4. 新增卡片需要同时加 card.bin 节、`Dxx.tga` 贴图（在 tex0000.dat 内）和脚本，exe 中卡片上限未验证。
