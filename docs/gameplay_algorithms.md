# 核心玩法算法（主代理逐行阅读反编译代码得出，已验证）

> 依据为 Ghidra 反编译结果（`out/ghidra_named/decompiled.c`，可用 `python scripts/simplify_c.py --named <函数名>` 查看去掉越界检查样板后的代码）。
> 下文的“结构偏移”均为相对对象起始地址的偏移。

## 1. 全局游戏状态 g_GameState（DAT_00632dcc）

| 偏移 | 含义 | 依据 |
|---|---|---|
| +0x04/+0x08/+0x0C/+0x10 | 当前日期：年 / 月 / **日** / 星期 | 存档样本：2026-11-10 星期二；`Role.GameDay()` 读 +0x0C（AI_01 中的 `d <= 7`、`d >= 26` 判断的就是月初/月末） |
| +0x14 | **已进行天数** | `Role.GameDate()` 读 +0x14；存档 record_08 中为 201 |
| +0x18/+0x1C/+0x20/+0x24 | 开局日期（年 / 月 / 日 / 星期） | 存档样本 |
| +0x2C | 物价基数 = 100000（即开局现金） | 存档样本中固定为 100000 |
| +0x30 | **物价指数**（1~99） | `Role.PriceIndex()`；租金、AI 阈值都乘以它 |

> 更正：exe_internals.md 早期把 +0x0C 写成“天数”、+0x14 写成“日期”，含义正好相反，以本表为准。

## 2. 物价指数（Game_UpdatePriceIndex @0x4A6A00）

```
若 指数 < 99：
    净资产(角色) = 现金 + 存款 − 贷款 + 股票市值 + 地产价值        (Role_CalculateNetCash @0x490140)
    平均净资产 = Σ 未破产角色的净资产 / 未破产角色数
    新指数 = min(99, 平均净资产 / 物价基数)      // 物价基数 = g_GameState+0x2C = 开局平均(现金+存款)，默认选项下为 100000（见 rules_land.md §5.1）
    指数只增不减：仅当 新指数 > 当前指数 时更新
```
所以当全场平均净资产达到 20 万时物价翻倍，30 万时变为 3 倍……最高 99 倍。

## 3. 过路费（Terra_CalcRent @0x4EFDA0）

```
住宅：单块租金 = RentTable[等级] × 街道系数(street.bin price) / 100
      RentTable(0x5E65B0，文件偏移 0x1E65B0) = 500, 1000, 2500, 5000, 8000, 12500   （等级 0~5）
      连锁：同一街道上同一地主的其他住宅地，各自按上式累加
      最终 = 合计 × 物价指数
商业建筑：建筑对象虚函数(+0x44) 的值 × 4
```

## 4. 股价（Stock_UpdatePrices @0x4B9A00，每个游戏日调用一次）

股票对象字段：+0x100 发行价（stock.bin 的 initprice）、+0x104~+0x343 最近 144 天的价格历史（每天整体后移一格）、+0x344 历史最高价、+0x348 历史最低价、+0x34C **当前价**、+0x350 **活跃度**（stock.bin 的 vivacity）、+0x358 停牌剩余天数、+0x35C/+0x360 个股事件的强制涨跌幅 / 剩余天数、+0x364 **动量**、+0x368 **当日涨跌幅(%)**、+0x36C 平稳计数。
管理器字段：+0x34/+0x38 全市场事件的强制涨跌幅 / 剩余天数；+0x3C 大盘涨跌比 =（Σ今价 − Σ昨价）/ Σ昨价。

正常交易日（无全市场事件）：
```
大盘噪声 M = (rand()%84 − 40) / 10                     → −4.0% … +4.3%
对每支未停牌、无个股事件的股票：
    昨价 = 今价
    若 昨价 < 10 → Stock_ResetStock：清空所有玩家的该股持仓，按发行价重新上市（标志 +0x374==1 的股票除外）
    d = (rand()%213 − 100)/10 × 活跃度                  → 约 −10 … +11.2 再乘活跃度
    70% 概率：d += (rand()%212 − 100)/10 × 0.4
    若 d > 10，70% 概率 d /= 2
    动量 = clamp(动量 + d, −10, +10)
    当日涨跌 r = clamp(M + 动量, −10, +10)
    价位修正（相对发行价 P0）：
        P0/3 ≤ 昨价 ≤ 4·P0：平稳计数 +1
        昨价 > 4·P0（过高）：r>0 时 20% 概率 r=−10、否则 r/=2；r<0 时 r×=2
        昨价 < P0/3（过低）：r>0 时 60% 概率 r×=2、40% 概率 r×=3；r<0 时 64% 概率 r=6、16% 概率 r=10、20% 概率 r/=2（r=0 不变）
    平稳计数 > 3：清零，并以 90% 概率 r ×= 1.5
    |r| > 8.5 时 50% 概率 r = r × (rand()%80)/100              （抑制连续大涨大跌）
    r = clamp(r, −10, +10)                                   （即 ±10% 涨跌停）
    今价 = 昨价 × (100 + r) / 100，上限 999.99，按规则取整（Stock_RoundPrice）
    更新历史最高 / 最低
```
- 全市场事件期间：今价 = 昨价 × (100 + 全市场强制涨跌幅) / 100（例如新闻“股市大涨/大跌”）。
- 个股事件期间：今价 = 昨价 × (100 + 个股强制涨跌幅) / 100，剩余天数 −1（例如红卡、黑卡）。
- 停牌：停牌天数 −1，价格不变。

**调整建议**：stock.bin 中的 `vivacity` 直接作为 d 的乘数，0.5 的股票波动约为 1.0 的一半；想让股市更刺激，就把 vivacity 普遍调到 1.5 以上。“低于 10 元退市并清空持仓”是原版规则，玩家持有的低价股有归零风险。
