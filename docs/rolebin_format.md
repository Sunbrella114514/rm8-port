## 游戏用途结论

**role.bin 的用途**：**角色动画与骨骼数据定义文件**

**证据**：
1. 文件名 "role" 表示角色
2. 与 RenderWare 模型文件 (`clump/article`) 和纹理文件 (`texture/article`) 一起加载
3. count2 数据块包含 .ANM 动画文件路径（RenderWare 动画格式）
4. count3 数据块大小（548 字节）和结构（包含浮点数）与动画关键帧/骨骼变换相符
5. 加载类管理场景对象/角色模型

**具体包含内容**：
1. **角色模型基础信息**：主体数据（0x650 字节）
2. **动画列表**：count2 数据块 - 每条 296 字节，包含 .ANM 文件路径
3. **动画帧/骨骼数据**：count3 数据块 - 每条 548 字节，包含骨骼矩阵或关键帧信息
4. **几何数据**（可能）：count4、count5 数据块 - 包围盒、碰撞盒或挂点数据

**游戏中的应用**：
- 当角色进入游戏场景时加载此文件
- 将动画绑定到角色模型
- 设定角色的动作集和行为参数
- 可能用于 NPC 定义、玩家角色皮肤等
